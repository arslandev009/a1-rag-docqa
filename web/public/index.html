What to look for

  • Citations. Every claim points at a document section, or the answer becomes an abstention.
  • Current policy only. The old 30-day refund policy and the internal runbook are in the database but filtered out in SQL before ranking.
  • Plan-aware answers. Limits differ by plan, so the answer must say so.
  • Honest “I don’t know”. Questions the docs cannot answer are refused, not guessed.

How it was measured

60 labelled questions, graded by two different LLM judges plus rule-based leak checks. Latest run: 0 leaks, every refusal and abstention correct, no known wrong answers. That run is in-sample on a small corpus, so read the failure analysis next to the numbers.
